# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in `pup-finetune`, please report it
privately by emailing [security@datadoghq.com](mailto:security@datadoghq.com).

**Do not open a public GitHub issue, discussion or pull request for a security vulnerability.**

Please include as much of the following as you can:

- a description of the issue and its impact;
- the version of `pup-finetune` (`pup-finetune --version`), your OS and Python version;
- steps to reproduce, or a proof of concept;
- any known mitigations.

Do not include real credentials, API keys or customer data in your report. We will acknowledge
your report, keep you informed as we investigate, and credit you in the fix if you wish.

## Supported versions

Security fixes are made only for the latest release. Please upgrade to the latest release before
reporting, and confirm the issue still reproduces there.
